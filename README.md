# Hyperscape SPZ tools

Browser viewers for Hyperscape SPZ scans. Files stay on the device.

- [Desktop viewer](https://adc103.github.io/hyperscape-spz-tools/viewer/desktop.html). Open an SPZ, drag to look, and use WASD and Q/E to move.
- [Quest viewer](https://adc103.github.io/hyperscape-spz-tools/viewer/quest.html). Open an SPZ in the Quest browser and select **Enter VR**. Push the left stick forward to aim and release to teleport. Flick the right stick to snap turn.
- [Export a Quest capture](docs/extract.md). Pack the SPZ, scene mesh, and visibility files into one ZIP.
- [Convert SPZ to standard PLY](docs/conversion.md). Fit standard Gaussian splats to RayQuadratic reference views.
- [SPZ file guide](docs/scan-files.md) and [Rendering reference](docs/rendering.md).
- [Viewer feature comparison](docs/viewers.md).

For local desktop use, clone the repo and open `viewer/desktop.html`. Immersive WebXR on Quest requires HTTPS.
