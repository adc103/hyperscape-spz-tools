Frame settings format

Optional eyes (one or two) each have position, forward, down, right (unit vectors in the scan's coordinates), tan (two positive half-FOV tangents), and optional NDC shift and fovea. Each eye can include depth with width, height and meters (top-to-bottom linear camera depth, 0 for unknown).

Optional top-level controls are near, far, width and height (full-resolution intermediate per eye), depthOffset, foveationRadius, mipFadePercent, detailNear, detailFar, distanceNear, distanceFar, detailFade, frontToBack (boolean), maxSplats, gpuBudgetMs, clipDepth (0.01 or 0.99), and alpha with power, threshold, boost, offset, cutoff, and unpremultiply.

The browser viewer uses its own visibility compaction, GPU timer feedback, and two-resolution layer sizes. Quest runtime settings can be supplied where exposed above.
